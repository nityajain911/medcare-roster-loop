Plans don't lack a way to collect roster updates. They can't confirm a change reached every system.

MedCare Roster Loop reads a messy roster file from a small practice, checks every row against fixed rules, routes each change by type, gets the plan's approval where needed, and only marks a change Applied once every destination system confirms it. Then it tells the practice the change is live.

Start the demo

The loop, in six clicks

  1. PracticeLakeview's practice admin sees the roster on file and drops in a messy file.
  2. What changedColumns are mapped, every row is checked and routed, with a reason.
  3. Plan queueNorthwind's analyst approves the new clinician and the back-dated removal.
  4. ReconciliationThe provider database takes each change; the directory rejects one. The analyst fixes it and resends.
  5. Practice statusLakeview sees each change reach Applied and go live.
  6. DashboardThe share of records confirmed and current, computed from this demo.
